# `dot-js` package

This folder is the **framework** workspace package (`name`: `dot-js`). Source lives in [`src/`](src/); hand-written documentation lives in [`docs/`](docs/).

- **Import in apps:** `import { h, mount, createStore } from 'dot-js'` (after `npm install` at the repo root).
- **No build step** for the framework yet — Vite consumes the ESM sources directly.

See the repository root [README.md](../README.md) for install and dev commands.
